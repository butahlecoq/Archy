# Current CLI and demo boundary

The source CLI at this commit exposes `desktop`, `doctor`, `init`, `validate`, `generate`, `compare`, `evaluate`, `render`, and `export-ifc`. `desktop capabilities --json` lists `project_status`, `run_status`, `open_report`, `open_preview`, and `open_blender`; the open operations report availability based on the viewer executable. `render` and `export-ifc` use supervised worker boundaries and publish run artifacts; IFC exports are marked `DRAFT`. `doctor --json` reports prerequisites; it does not launch or authorize a worker.

`scripts/demo.py` takes `--archy` (default `archy`), optional `--project-dir` (must be absent), `--name` (default `courtyard-demo`) and optional `--export-variant` (selection intent only; no export occurs). It creates a fresh project from the packaged courtyard brief, validates it, calls `generate --count 3 --seed 42 --json`, `evaluate --all --run <generated-run> --json`, and both forms of `compare --run <generated-run>`. The driver reads actual receipts and refuses mismatched variant IDs. It prints every command, output and exit code. Comparison copies are created without overwrite; immutable run artifacts are produced by the CLI.

After comparison, the current driver always exits 2 and keeps the project. With this CLI it reports that the `render`/`export-ifc` receipt and artifact contract is unavailable; that stop message is stale because both commands are wired. The driver does not invoke either command, and `--export-variant` does not change that boundary. A18 driver integration and verification of real backend files remain open. Approval is never called by this driver; an export remains draft until a real local human decision event exists.

The comparison reports geometric area, simple repeated-footprint GFA, height and declared setbacks. Daylight, cost, structure, access and local regulation are uncomputed. Constraint authorities are unverified declarations, not certified law. The 900 m² GFA target is soft in the packaged example.
