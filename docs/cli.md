# Current CLI and demo boundary

The source CLI exposes `desktop`, `doctor`, `init`, `validate`, `generate`, `compare`, `evaluate`, and `render`. `desktop capabilities --json` lists `project_status`, `run_status`, `open_report`, `open_preview`, and `open_blender`; the open operations report availability based on the viewer executable. Render uses the fixed installed service gate and publishes an immutable structured receipt. The CLI does not yet expose IFC export. `doctor --json` reports prerequisites; it does not launch or authorize a worker.

`scripts/demo.py` takes `--archy` (default `archy`), optional `--project-dir` (must be absent), `--name` (default `courtyard-demo`) and optional `--export-variant` (candidate selector only; no export occurs). It creates a fresh project from the packaged courtyard brief, validates it, calls `generate --count 3 --seed 42 --json`, `evaluate --all --run <generated-run> --json`, `render --all --run <evaluated-run> --json`, and both forms of `compare --run <generated-run>`. Before listing verified artifact paths, the driver checks the receipts, render source, selected IDs, file lengths and SHA-256 digests against native accepted-run status. It prints every command, output and exit code. Comparison copies are created without overwrite; immutable run artifacts are produced by the CLI.

The driver exits 0 at `REVIEW READY` only when the CLI verifies the accepted render run, all three render results are verified, their artifacts match the retained receipt, and required checks pass. This is a handoff for human selection and visual inspection. A failed worker result, including `BACKEND_UNAVAILABLE` on WSL without the gate, exits 2 and leaves all accepted runs and comparisons intact. The printed idempotency key supports an exact render retry after an uncertain outcome. The driver does not call `export-ifc` or record approval. `--export-variant` must name an evaluated variant and only identifies a candidate for later review.

The comparison reports geometric area, simple repeated-footprint GFA, height and declared setbacks. Daylight, cost, structure, access and local regulation are uncomputed. Constraint authorities are unverified declarations, not certified law. The 900 m² GFA target is soft in the packaged example. Preserve the project and its run history for review; create a new project path for another demo.

Release gates still open include installed Omarchy render execution, IFC CLI publication and target execution, explicit human selection and approval, clean installation and version checks, target machine containment, visual review, independent IFC parsing, and recovery. WSL or injected protocol tests do not close those Omarchy gates.
