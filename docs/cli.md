# Current CLI and demo boundary

`archy --help` at integration base `ae6e6a6` lists `desktop`, `doctor`, `init`, `validate`, `generate`, `compare`, and `evaluate`. `desktop capabilities --json` currently lists only read-only `project_status` and `run_status`. The bounded Blender and IFC worker code is not a production CLI supervisor. `doctor --json` reports prerequisites; it does not launch or authorize a worker.

`scripts/demo.py` takes `--archy` (default `archy`), optional `--project-dir` (must be absent), `--name` (default `courtyard-demo`) and optional `--export-variant` (selection intent only; no export occurs). It creates a fresh project from the packaged courtyard brief, validates it, calls `generate --count 3 --seed 42 --json`, `evaluate --all --run <generated-run> --json`, and both forms of `compare --run <generated-run>`. The driver reads actual receipts and refuses mismatched variant IDs. It prints every command, output and exit code. Comparison copies are created without overwrite; immutable run artifacts are produced by the CLI.

After comparison, the current driver always exits 2 and keeps the project. With this CLI it reports `UNAVAILABLE: archy render is absent`; even if a CLI advertises `render`, it stops because the supervised backend receipt and artifact contract is unreviewed. It does not invoke `render` or `export-ifc`, and `--export-variant` does not change that boundary. A reviewed backend CLI contract and driver update are required before any render or draft IFC export can be claimed. Approval is never called by this driver; an export must remain draft until a real local human decision event exists.

The comparison reports geometric area, simple repeated-footprint GFA, height and declared setbacks. Daylight, cost, structure, access and local regulation are uncomputed. Constraint authorities are unverified declarations, not certified law. The 900 m² GFA target is soft in the packaged example.
