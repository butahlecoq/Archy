# Optional Herdr/tmux workspace

The Archy CLI and stdio MCP workflow work in any terminal and agent client. This layout is only a way to keep the brief, agent, logs and artifact review visible. It creates no Archy scheduler and supplies no authority to approve a variant.

On Omarchy 4.0.6, the default agent can be selected with `omarchy default agent <name>` and launched from a task with `omarchy agent prompt "Inspect this Archy project and its declared constraints"`. The launcher may use an unattended client mode; Archy's own project and human-decision boundary still applies. Run it from the project directory and connect the client to the operator-configured `archy-mcp --project /absolute/path/project.yaml` stdio server. Configure the client using its own supported MCP settings; do not paste a universal client config or require an API key. [Omarchy AI manual](https://github.com/omacom/omarchy/blob/v4.0.6/manual/17-ai.md)

For tmux, start from the project directory with `tmux new -s archy-review`. Keep one pane on the brief (`less project.yaml`), one on the agent, one on logs (`find runs -name '*.log' -print` followed by a chosen `less`), and one on artifact review (`find runs -type f | sort` plus a viewer chosen for the verified file). Use tmux's documented split/window commands or the keyboard bindings installed on that machine; do not script keystrokes into a running agent. The project can be reviewed in one terminal if tmux is absent. [tmux manual](https://man.openbsd.org/tmux)

If Herdr is installed, start it in the project directory with `herdr` and use its terminal UI to create a workspace, tabs and panes for the same four roles. Omarchy's pinned Herdr config maps tmux sessions to workspaces, windows to tabs and panes to panes, with new panes following the current directory. Confirm the installed version's shortcuts in its help/config. This playbook does not call Herdr's socket API or assume a socket path, and Archy never needs Herdr for the golden workflow. [Herdr README](https://github.com/omacom/herdr), [Omarchy 4.0.6 Herdr config](https://github.com/omacom/omarchy/blob/v4.0.6/config/herdr/config.toml)

After each mutation, keep the accepted revision/run ID and result visible in the logs pane. Inspect files only through the project-scoped paths in verified receipts. A pane title or agent statement is not a human approval record.
