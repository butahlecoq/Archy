# A22 installer rollback fix for independent review

Base commit: `15446eeaf316846936a093377041b8c1d2874092`. This handoff follows `a22-native-15446-review-fix-handoff.md` and the independent `rereview-sol.md`. The complete candidate diff is frozen at `/home/butahlecoq/work/archy/.tools/a22-native-15446-20261030/rollback-fix-full.patch`; hashes are in `rollback-fix-freeze.sha256` beside it. No other worktree was edited.

The re-review probe injected EIO at the final plugin lookup after `install.json` was linked. Before this fix, rollback deleted the owned plugin directory but left state, so a normal retry was refused as “owned plugin is missing.” The installer now parks the final entry through exclusive rename, verifies the moved inode is the staged inode, removes only the matching published state, then deletes the parked directory. If state removal fails, it restores the owned directory, leaving install and state coherent. A state file that differs from the expected record is preserved. An I/O error after the state link but during temporary-file cleanup is marked as a published-state failure, so rollback removes its matching state as well.

Evidence: the original `rereview-ext4/repro.py` now reports `post_state_rollback ... dest_absent= True state_present= False`; its install swap, uninstall swap, occupied restore, and symlink ancestor probes retain the earlier results. With `TMPDIR` set to that ext4 probe directory, `python3 -m unittest tests/omarchy/integration/test_install.py tests/omarchy/integration/test_plugin_contract.py -v` passed 19 tests. New tests first failed on the stale state and state-unlink failure, then passed after the fix. They also cover post-link temporary cleanup failure, ordinary retry, install/uninstall, and preservation of a neighboring plugin entry. `git diff --check HEAD` and Python compilation passed.

Tradeoffs: rollback cannot atomically update two directories. If deleting the parked owned tree fails after state removal, its private parked directory may remain; the final plugin name and state are absent, so retry can proceed, but manual cleanup may be needed. If another writer occupies the final name during restoration, exclusive rename refuses to overwrite it and leaves the parked directory for manual recovery. As in the prior handoff, arbitrary concurrent replacement after the last identity check is outside the guarantee. A failed unlink of the temporary state hard link can leave that private temporary file even when the published state and final plugin directory are rolled back. No installed Omarchy shell or graphical viewer acceptance is claimed here.
