# A09/A16 shared worker supervisor plan

Research date: 2026-10-29. Plan only; no implementation, installations, agents, commits or pushes. All tests below are future work. Omarchy is primary; WSL results are development evidence.
Inputs: [specification](../specs/release-0.1.txt) §§3.2,5,8,9; [A09/A16 backlog](backlog.md); [backend research](backend-research.md); [Blender plan](blender-worker-plan.md), [IFC plan](ifc-worker-plan.md), [task03 plan](task-03.md), [storage handoff](task03-storage-handoff.md), and current `storage.rs`/`run.rs` APIs. Current storage is under review; recheck its final contract before integration.

## Ownership and one shared interface

Create `crates/archy-adapters/src/{process,isolation,artifacts}.rs` plus `tests/backend/process_contract.rs` and security fixtures; extend existing adapter protocol modules rather than inventing a second worker protocol. Shared Cargo/CLI changes require coordination with their owners.
Proposed interfaces: `Supervisor::execute(job: ValidatedJob, cancel: &Cancellation) -> Result<VerifiedOutputs, SupervisorFailure>`; `ValidatedJob` contains backend enum, canonical typed request, existing run ID, approved preset, immutable runtime identity and limits. Constructors are private to validated adapter orchestration; no caller-supplied executable, argv, environment map, script/module name or arbitrary destination.
`VerifiedOutputs` owns bounded verified bytes and typed producer/media metadata, with private construction; `SupervisorFailure` carries existing ArchyError plus structured reason, bounded logs, termination evidence and retained scratch reference. It cannot assert approval or publish anything.
Caller retains `ProjectStore`/`LockedProject`: revalidate canonical source/variant and recompute evaluation, call `begin(RunRequest)`, return prior receipt without rerunning on replay, or retain `PendingRun` and its lock through execution/verification/commit. Preserve failed design checks independently of successful rendering; missing evaluation is evaluated or refused, never assumed passing.
Only the caller invokes `PendingRun::write(path, bytes, media_type, producer)`, `record_outcome`, and `commit(RunMetadata)`. Reuse task03 idempotency/revision validation, openat2 containment, hashes, fsync, no-replace publication and orphan recovery. No adapter revision ledger, final rename, manifest authority or CLI/MCP approval path.

Use std plus existing serde/schema/hash/rustix dependencies; no Tokio, nix, wait-timeout, custom syscall bindings or zbus dependency is needed for the initial synchronous one-job supervisor. Existing lock/license records cover rustix's selectable MIT option; recheck newly enabled graph/notices. Exact installed bubblewrap/systemd versions and supported options remain unknown, not inferred from current manuals.
Pidfds identify a single process and avoid recycled-PID signaling; they do not identify descendants. Obtain a pidfd immediately after spawning the direct child while retaining Child and preventing another reaper from collecting it; handle fast exit and syscall failure. For the recommended service path this child is **systemd-run**, not the worker: service lifecycle/cgroup identity is the production authority. Pidfd/process-group supervision of fixture helpers is useful but never substitutes for cgroup teardown.

## Fixed launch, isolation and resource policy

Blender inner argv: trusted absolute Blender binary, `--background --factory-startup --disable-autoexec --offline-mode --python-exit-code 20 --threads 1 --python /runtime/workers/blender/worker.py -- --request /job/input/request.json --response /job/output/response.json`.
IFC inner argv: trusted venv Python, `-I -m archy_ifc_worker --request /job/input/request.json --response /job/output/response.json`; require packaged module/import smoke from A11. Never silently switch to system Python or another Blender. Resolve/hash-check runtime and worker inventory outside writable project data.
Build every layer as argument arrays, never shell text. Clear environment again inside the sandbox (user services may inherit manager environment); allow only fixed locale, timezone, private HOME/XDG/tmp values and needed runtime settings. Remove PYTHONPATH, PYTHONHOME, LD_PRELOAD, LD_LIBRARY_PATH overrides, proxy/credential variables, display/Wayland and session-bus addresses; no host cwd or project imports.
Required bwrap profile: explicit `--unshare-user --unshare-pid --unshare-net --unshare-ipc --unshare-uts`, `--die-with-parent --new-session --cap-drop ALL`, empty root, audited read-only runtime/library/font mounts and input, private proc/minimal dev, private temporary HOME/cache, and only scratch output writable. Do not use `*-try` namespace options, host `/` binds, host `/home`, `/run/user`, D-Bus/agent sockets, cgroup filesystem or GPU devices. Mount-root read-only after constructing required writable submounts; account for every writable mount.
No network namespace sharing; no inherited socket/file descriptors except explicit control/stdin/stdout/stderr. Closing host sockets matters: a new network namespace does not invalidate an already-open host socket. CPU headless profile requires no compositor/GPU access. GPU access is a separately reviewed future profile.
Proposed initial smoke policy: request/response <=1 MiB each, worker wall time 120 s, total job including setup/verification 180 s, 2 GiB `MemoryMax`, zero swap allowance, `CPUQuota=100%`, `TasksMax=64`, 2 s stop grace, 1 MiB captured per diagnostic stream. Set `RuntimeMaxSec` as manager-side upper bound and `LimitCORE=0`; cap file size to the storage-compatible limit. CPUQuota is a rate limit, not a total CPU-seconds budget.
Use a fixed trusted launcher helper in the transient service: it waits for a bounded start token on the inherited control pipe before executing bwrap. Supervisor first verifies job identity and effective cgroup limits; only then releases the token. EOF/startup deadline exits without executing the worker. This avoids running a worker before discovering unenforced limits; the helper is packaged code, not an exposed arbitrary execution tool.
Create scratch through a private descriptor-pinned root, separate from task03 staging. A writable host output directory requires an **actual per-job byte/inode quota or dedicated bounded filesystem** provisioned by the target environment. Proposed 128 MiB aggregate/256 files; polling or `RLIMIT_FSIZE` alone is insufficient against many files. If hard scratch accounting is unavailable, production launch fails closed. This provisioning/API choice remains an explicit implementation blocker; no silent unlimited directory fallback. Bwrap tmpfs scratch is an alternative only with a designed bounded extraction channel, not automatic host-path visibility.
Task03 currently caps each artifact at **16 MiB**, aggregate **256 MiB**, and count **4096**. Enforce the lower limits before copying; reserve room for request/evaluation/log/error evidence. `.blend` may exceed 16 MiB despite the worker's 128 MiB aggregate proposal: refuse explicitly or obtain a reviewed storage-owner streaming/limit change; do not enlarge limits or bypass `PendingRun::write` in A09.

## Lifecycle, verification and immutable publication

1. Validate/evaluate and obtain pending run through caller authority; allocate unique job identity bound to run ID, freeze typed request and trusted runtime/policy identity, then create private read-only input and quota-bound scratch. Worker sees `/job/*`, never the project or accepted-run tree.
2. Start gated service with all limits installed. Check user manager, cgroup v2 controllers, job membership and property values; establish timeout/cancellation tracking and bounded pipe draining before releasing start token. Capture exact effective policy, runtime digest and environment provenance without secrets.
3. Drain stdout/stderr concurrently with deadline checks; avoid unbounded `output()`/`wait_with_output()`. On cap breach terminate the job with a quota reason while retaining a bounded prefix/tail and omitted-byte count. Never stop draining a live child and deadlock on a full pipe.
4. On timeout/cancel/protocol or quota failure, request unit stop (TERM then KILL at 2 s); use whole-unit kill/escalation, not only wrapper/leader kill. Verify service inactive and `cgroup.events populated=0`, reap the direct child, and drain/close pipes with a deadline. Process groups miss `setsid`/double-fork escape; cgroup containment must cover these. Do not reuse staging while termination is uncertain.
5. Supervisor death must still be bounded: manager RuntimeMaxSec and control-pipe EOF before launch; bwrap parent-death behavior alone is insufficient because the manager owns the service. Test crash cleanup. Missing manager access during teardown is a containment failure, never successful cancellation; retain job ID/evidence for recovery.
6. After all writers are gone, open scratch outputs descriptor-relatively with the task03-style `openat2` resolution policy; require regular single-link files, exact names/count, size budgets, no symlinks/FIFOs/devices/sparse-size bypass. Reject undeclared extras, duplicate response entries, invalid UTF-8/duplicate JSON keys/unknown fields, nonfinite values and wrong schema/IDs/digest/versions. Exit 0 is only one prerequisite.
7. Read bounded bytes once, recompute SHA-256 and compare worker claims. Verify from those same bytes/read-only snapshots, then publish precisely those verified bytes to avoid verify/reopen races. Same-user hostile host processes are outside an authentication boundary, as in task03; detect corruption and refuse, do not claim complete protection from them.
8. Reuse [artifact-reader recommendations](../research/artifact-readers.md) for independent PNG decoding/foreground and GLB world-instance transforms, inverse Y-up, bounds and closed-volume checks; compare canonical evaluations with versioned tolerances. Missing readers fail verification, not a header-only fallback. Parser subprocesses receive the same containment/resource policy with read-only artifacts and bounded results.
9. For IFC, fresh-process reopen/validation checks units/hierarchy/placements/draft properties and geometry, not just schema exit status; A13 owns second-engine verification. IfcOpenShell reopening is not independent-engine proof. `.blend` reopen uses the pinned trusted runtime with autoexec disabled under the same sandbox; never load worker-supplied scripts. Preserve distinct verification levels; unresolved required checks block accepted artifact publication.
10. On success caller writes verified outputs/provenance through PendingRun, records outcomes and commits. On failure caller may record bounded failed-run evidence/outcome via that same API, never mark partial artifacts accepted. Retain quarantined scratch references and failures within quotas; do not delete existing runs. Propagate uncertain storage commit errors unchanged and retry the same request key through task03 recovery.

## Error and availability policy

Missing runtime/reader/namespace/user-manager/controller/quota capability => `BACKEND_UNAVAILABLE` with stable reason and remedy; no sudo, auto-install, isolation downgrade or unconstrained worker path. Unsafe caller paths => `PERMISSION_DENIED`; malformed request => `INVALID_SCHEMA`; malformed/incorrect artifacts => `ARTIFACT_INVALID`; wall timeout => `BACKEND_TIMEOUT`. Explicit cancel returns a structured `cancelled` supervisor reason through the existing error envelope (proposed `BACKEND_TIMEOUT` until owner reviews a distinct code), never success. Preserve resource/OOM/exit/signal causes in diagnostics rather than inventing worker results.
A21 doctor only observes availability; active probes/limits belong here. Fixture transport is test-only and cannot be selected by a production request/env override. WSL lacking controllers or namespaces must show unavailable for production jobs while still running pure contract tests.

- [ ] **Isolation/quota:** test host-home secret read, project/accepted-run write, DNS and direct IPv4/IPv6 connection, host UNIX socket access, leaked FD, cgroup migration, GPU-device access and mount/symlink escape. - [ ] **Artifact bridge:** corrupt/truncated PNG/GLB/IFC, blank previews, bad hashes, repeated/missing/unexpected files, open/inverted meshes, transformed instances, L-notch loss, wrong IFC units, symlink/hardlink/FIFO swaps and late-writing descendants. - [ ] **Storage integration:** replay skips worker, stale revision/key conflict creates no job, interrupted verification publishes nothing successful, occupied final path never overwrites, commit/fsync uncertainty uses task03 retry semantics. ## Coordinator follow-up: bounded tmpfs descriptor handoff candidate

The storage and process boundaries now have scoped independent passes; production service, quota and artifact authority remain unimplemented. A new candidate may resolve scratch extraction without making a host output directory writable. It must be proved before selection for production.

Primary evidence checked on 29 October 2026: [systemd.exec 258](https://www.freedesktop.org/software/systemd/man/258/systemd.exec.html) documents `TemporaryFileSystem` with mount options in user services when the required private-user-namespace support exists. [Kernel tmpfs documentation](https://docs.kernel.org/filesystems/tmpfs.html) defines nonzero `size` and `nr_inodes` bounds; these are distinct from per-user quota features. [open(2)](https://man7.org/linux/man-pages/man2/open.2.html) permits descriptor-relative operations and passing O_PATH descriptors over Unix sockets; [unix(7)](https://man7.org/linux/man-pages/man7/unix.7.html) documents SCM_RIGHTS. Inference to test: a supervisor-held directory descriptor can retain access to the job's private tmpfs after its service namespace and every worker writer have gone.

Candidate sequence:

1. Give each transient service one private tmpfs job filesystem with explicit byte/inode limits, restrictive modes, nosuid/nodev and measured swap policy. Put every writable output, HOME/cache/temp location on that filesystem. Bind immutable inputs separately. Bwrap still supplies the explicit empty-root, runtime allowlist and network/socket/device policy; a tmpfs alone is not isolation.
2. Before any worker starts, a fixed trusted gate helper opens the scratch root and passes exactly one close-on-exec directory descriptor through a supervisor-created Unix control socket. Check framing, descriptor count/type/ownership/filesystem identity and effective byte/inode capacity, as well as the service cgroup limits. Reject missing or mismatched evidence before releasing the start token. Close the control channel before executing the worker; no general host socket or namespace handle reaches it.
3. Stop/kill the whole service and establish inactive/empty-cgroup state before reading outputs. Use the retained descriptor and the reviewed bounded artifact capture policy to read the same immutable bytes that will be independently parsed and passed to storage. No `/proc/PID/root` reopening, host mount, late trusted-copy process in a live worker group, or unlimited scratch fallback.

Required first proof is a disposable WSL kernel fixture, not a backend launch: real nonzero byte and inode exhaustion; FD handoff with strict ancillary-message validation; child/namespace exit; retained-descriptor reads; unchanged host backing-directory/outside sentinels; and release after final descriptor close. Then separately test the actual systemd user-service control-FD transport, mount options, cgroup property enforcement and whole-service teardown. `systemd-run --pipe` forwarding an inherited socket must be verified rather than assumed. Missing capabilities remain `BACKEND_UNAVAILABLE`.

Development observations so far: `systemctl --user is-system-running` returned `running`, and `unshare --user --map-root-user --mount -- /usr/bin/true` exited 0. The bare `systemd --version` command was absent from PATH; `systemctl --version` separately reported systemd 259 (259.5-0ubuntu3.4). Fixed `/usr/bin/systemd-run`, `/usr/bin/mount` and `/usr/bin/unshare` exist. No tmpfs, service, quota exhaustion, descriptor transfer or backend was exercised by these probes. Actual Omarchy gates remain deferred, and the existing 16 MiB artifact storage bound remains unchanged.
