# Blender worker round 1 independent rereview

**Snapshot:** frozen round 1 Python worker and WSL evidence in `blender-worker-handoff.md`, 2026-10-29. Scope is the three findings in `blender-review-final.md` and regressions introduced by their fixes. No source edits, commits, agent delegation, or full-suite rerun.

## Verdicts

1. **High far-coordinate parity finding — resolved for the bounded worker.** `workers/blender/scene.py:74-84` compares each constructed storey vertex in world space with the corresponding canonical footprint point and lower/upper elevation before export. It raises `BACKEND_UNAVAILABLE` at errors above 1e-6 m. The targeted native test `test_far_inexact_world_coordinates_fail_capacity` passed for positive and negative inexact origins. The retained `inexact/` response reports `0.000403124999 m` and `artifacts: []`, and its directory contains only request and response files; the handoff records exit 20. The targeted native `test_far_exact_world_coordinates_export_without_translation_loss` passed for ±9990.125 m; it checks inverse-axis-converted GLB vertices/bounds against canonical points. The retained exact response reports zero maximum world error and five matching artifact hashes. This is an explicit capacity refusal for unrepresentable coordinates, not a widened tolerance or silently changed geometry.

2. **Medium nested response validation finding — resolved for the Python contract.** `workers/blender/protocol.py:94-175,299-314` now requires exact nested geometry and preset keys; it checks finite positive area/volume/bounds, the recorded world-error budget, fixed CPU/render/export settings, and nested world/material/camera/object/light structures. `tests/backend/blender/test_protocol.py:84-103` rejects changed engine/device/samples, unknown fields, nonfinite values, excessive world error and changed world/material/export settings. All 8 protocol tests passed independently. The retained exact success response also passed `validate_response()`.

3. **Low preset provenance finding — resolved for the fixed smoke preset.** `workers/blender/worker.py:61-159` records the settings previously omitted: thread mode, compression, transparency, display/look, unit/frame, world node color/strength, material node values, light color/transform, camera clips/matrices, object transforms and saved relative render path. `tests/backend/blender/test_blender_integration.py:79-104` compares the entire returned preset and geometry summary across two jobs per analytic shape. The handoff reports this test inside its 15-test WSL suite; I inspected its assertion and the retained exact response, but did not rerun the repeat render. Pixel identity across hardware is not claimed.

**New breakage from these fixes:** none found in the reviewed source, targeted tests or retained jobs. Strict response validation can still turn a produced job into an error with unaccepted partial files if a future Blender setting differs; A09 staging and publication must handle those files. This is not an accepted-artifact claim.
