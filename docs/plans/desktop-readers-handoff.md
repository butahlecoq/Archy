## Reader and wire contract

`ProjectStore::read_history()` does not call `lock()`, create directories/files, sync, replay, or recover. It reuses descriptor-relative no-symlink opens, private managed-directory ownership, bounded revision/manifest/artifact reads, receipt hashes, chain sequence, and artifact inventory checks. An absent `.archy` is revision-zero genesis; an existing `.archy` without `revisions` is `ARTIFACT_INVALID`. `AcceptedHistory` holds the validated revision prefix and its head hash. A later writer append does not change that object; selected run reads recheck bytes against the accepted record. `LockedProject` still performs its existing lock/bootstrap/durability/replay flow and uses the same validator.

`run_integrity::verify_history()` is shared by locked mutators and desktop status. It verifies ancestry and canonical source/normalized, generation, variant, full evaluation, report, and event bytes. Desktop status never promotes a merely rehashed but semantically forged evaluation.

`archy desktop capabilities --json` reports protocol `archy-desktop-capabilities-v1` and only `project_status` and `run_status`. No open, preview, Blender, process, job-start, or approval operation is advertised. `archy desktop status --project FILE [--run ID] [--limit N] [--cursor TOKEN] --json` reports protocol `archy-desktop-status-v1`, current project ID/source digest and accepted revision, newest-first verified run summaries, one selected run's verified artifact IDs/kinds/lengths/hashes, and fixed `backend_jobs.status: unknown` with a reason. `--run` must name an accepted run; by default the first run on the page is selected. Artifact metadata is data only and grants no launch/open authority. Historical runs for the same project ID remain readable after current source edits; cursors bind to current source digest and thus become stale on such edits.

Page limit defaults to 20 and is restricted to 1..=100. Cursor tokens bind the pinned project root identity, project ID, source digest, revision, revision-head hash, and next offset. An append or binding change returns `REVISION_CONFLICT` and asks the client to restart at page one. The pretty JSON response is capped at 1 MiB; no source, report, event, variant or evaluation file body is emitted. Core's reviewed per-file, per-run and 100,000-entry history bounds remain in force. Job state is unknown because no A16 supervisor observation is read here.

## ASCII JSON transport addendum, same review freeze

The GUI process integration found that Quickshell's `SplitParser` may decode arbitrary UTF-8 byte chunks independently. The follow-up adds `crates/archy-cli/src/ascii_json.rs` and `crates/archy-cli/tests/ascii_json.rs`, with narrow dispatch changes in `lib.rs` and `main.rs`. The helper first serializes with the existing `serde_json` compact or pretty serializer, then replaces every non-ASCII scalar with JSON `\u` escapes; non-BMP scalars use UTF-16 surrogate pairs. Existing ASCII output remains byte identical. Parsed values, schemas, protocol versions and CLI flags are unchanged. `doctor --json` and desktop success JSON use the pretty helper; JSON error output uses the compact helper for all CLI commands, including doctor and desktop failures. Other successful CLI output remains on its previous serializer. No new dependency or package version was added.

Focused `RUSTUP_AUTO_INSTALL=0 CARGO_NET_OFFLINE=true cargo test --locked -p archy-cli --test ascii_json` exited 0 with 3 passed. Tests cover BMP and non-BMP characters, surrogate pairs, quotes, backslashes, control escapes, literal escape text, parsed-value roundtrips, every byte split of the ASCII result, real doctor/desktop CLI JSON, and a Unicode-path CLI error. Follow-up `cargo fmt --all -- --check`, strict locked workspace clippy, and `python3 scripts/check-schemas.py` each exited 0. Final `RUSTUP_AUTO_INSTALL=0 CARGO_NET_OFFLINE=true cargo test --locked --workspace` exited 0: 132 passed, 0 failed, 1 preexisting optional native test ignored across 26 result groups; `ascii_json` 3, `core_workflow` 16, `desktop_readers` 6, `golden_artifacts` 1, and `storage` 20 passed.
