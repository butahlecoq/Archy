The H3 CLI command is `archy desktop open --project <absolute manifest> --run <accepted UUID> --artifact <verified artifact ID> --kind report|preview|blender --json`. It reads the H2 accepted snapshot, semantically verifies the run, re-reads hash-verified artifact bytes, checks exact kind/path, and hands a private runtime copy to a fixed viewer argv. It returns the bounded `archy-desktop-open-v1` receipt with status `handed_to_viewer`; it does not claim display, render, IFC, approval or professional compliance. No executable, shell command or argument vector comes from project/worker/status data. `/usr/bin/xdg-open` handles report/PNG; `/usr/bin/blender --factory-startup --disable-autoexec` handles a verified `.blend`. The panel binds the click and receipt to the selected verified run, artifact and digest, refuses stale status and malformed receipts, and cancels in-flight open requests on close/selection changes. Current accepted core runs supply reports; no preview or scene is fabricated while render/IFC/authority integration is pending.

`integrations/omarchy/install.py` previews by default and applies only on `--apply`. It copies the standalone `integrations/omarchy/plugin/` root into the user plugin root after exact inventory/manifest/symlink checks, records ownership hashes, refuses unknown collisions/edits/upgrades, and is idempotent. `uninstall.py` previews or moves the unchanged owned plugin to an exclusive user-state backup, preserving unrelated files. The uninstall works if the source package was removed. The installer does not edit package-owned `/usr/share/omarchy`, `shell.json`, shared menu/Lua/hook files, or enable the plugin. Fixed optional examples are supplied for manual user review; automatic config merges remain outside this patch because arbitrary JSONC/Lua editing cannot be proven safe without target evidence. See `docs/omarchy/desktop.md`.
