## Finding and correction

Rereview 6 showed that the actual three-part framed bridge accepted `Certified` in an active `IFCPRODUCTDEFINITIONSHAPE.Name`, `Approved for construction` in its Description, and approval or certification text in `IFCRELAGGREGATES` and `IFCRELDEFINESBYPROPERTIES` descriptions with unchanged accepted source. The common cause was that entity inventory and graph membership did not constrain every semantic field on those reachable nodes.

The reader now checks the exporter-generated null metadata for every relevant allowed entity type, including all relation Name/Description fields, shape Name/Description, root OwnerHistory, project/site/building/storey optionals, proxy Tag, provenance and quantity descriptions, SI prefixes, context options, and curve options. The STEP scope enforces the IFC4 field count for all 27 supported DATA entity types and requires the exporter's derived `*` slots in SI units and body subcontexts, so hidden extra fields cannot pass through a lenient web-ifc parse. Existing checks continue to bind dynamic names to expected project/variant IDs, provenance properties to the accepted source and DRAFT state, and dimensions/geometry to rectangle or L expectations. Root GUIDs are now checked against the exporter's UUIDv5 semantic-role derivation, so a syntactically valid but forged GUID cannot carry an extra claim.

## Allowed entity schema audit

The STEP scope permits exactly 27 DATA entity types present in each generated fixture, plus three typed values (`IFCBOOLEAN`, `IFCLABEL`, `IFCREAL`). The table identifies the checked fields for every entity schema. Null fields are enforced by `checkNullMetadata`; named/dynamic fields and numeric/reference fields are checked by `inspectGraph`, `inspectMeshes`, or `checkStepScope`. `*` denotes an IFC derived slot in the exporter output.

| Entity types | Supported field policy |
| --- | --- |
| `IFCPROJECT`, `IFCSITE`, `IFCBUILDING`, `IFCBUILDINGSTOREY`, `IFCBUILDINGELEMENTPROXY` | Source-bound Name, exact null optional metadata, exact proxy DRAFT Description/ObjectType/PredefinedType, source-bound storey elevation and placements, active project context/unit references, deterministic GUID |
| `IFCRELAGGREGATES`, `IFCRELCONTAINEDINSPATIALSTRUCTURE`, `IFCRELDEFINESBYPROPERTIES` | Exact null OwnerHistory/Name/Description; exact endpoint/member sets and counts; deterministic GUID |
| `IFCPROPERTYSET`, `IFCELEMENTQUANTITY`, `IFCPROPERTYSINGLEVALUE` | Fixed set names and method, null optional metadata; exact 15 property names, typed/source-bound values, DRAFT, timestamp form, member sets and counts; deterministic set GUIDs |
| `IFCQUANTITYAREA`, `IFCQUANTITYVOLUME` | Fixed names/formulas, null descriptions, active units, source-bound quantities and exact membership |
| `IFCGEOMETRICREPRESENTATIONCONTEXT`, `IFCGEOMETRICREPRESENTATIONSUBCONTEXT` | Exact type/identifier, precision, dimension, null TrueNorth and optional targets; active parent and world identity |
| `IFCPRODUCTDEFINITIONSHAPE`, `IFCSHAPEREPRESENTATION` | Null shape Name/Description; exact body identifier/type/context, proxy membership and swept solid items |
| `IFCARBITRARYCLOSEDPROFILEDEF`, `IFCINDEXEDPOLYCURVE`, `IFCCARTESIANPOINTLIST2D` | Fixed area profile/name, null curve Segments/SelfIntersect, one source-bound rectangle or L outline and mesh |
| `IFCEXTRUDEDAREASOLID`, `IFCAXIS2PLACEMENT3D`, `IFCLOCALPLACEMENT`, `IFCCARTESIANPOINT`, `IFCDIRECTION` | Exact active swept profile and depth, transformed identity/origin/elevation, world vectors, closed mesh bounds/area/volume/notch; no free text fields |
| `IFCSIUNIT`, `IFCUNITASSIGNMENT` | Exactly three SI units with fixed types/names, null prefixes, exact active assignment; no free text fields |

The table-driven framed corpus inventories all 27 fixture types, mutates each free-text semantic field of each applicable type with `Certified and Approved for construction` on both rectangle and L, and asserts `ARTIFACT_INVALID`. It also adds and removes one field from every entity type in both fixtures and checks that the STEP scope rejects each arity mutation; a changed derived slot is tested through the framed bridge. Separate framed cases cover context north/precision/identity, curve self-intersection, SI prefix, provenance/quantity duplicates, and a valid-looking forged root GUID. Tests keep source bytes and expected JSON fixed for each mutation. Ordinary rectangle and L retain their names from expected project/variant identity and preserve their actual profiles and meshes.
